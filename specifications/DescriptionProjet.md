# Simulateur de Faluche

Le but de ce projet est de creer un simulateur de faluche en ligne, qui permet de dessiner une faluche schematique en fonction de l'interaction de l'utilisateur. Le resultat "type" sera une image schematique de la faluche un peu comme sur le fichier FAL.png dans ce repertoire.

## Description du projet

Le simulateur de Faluche est un outil qui permet de dessiner une faluche schematique en fonction de l'interaction de l'utilisateur.
La faluche est un folklore étudiant qui consiste dans le port d'un chapeau emblématique (une falluche) dont les différents rubans et insignes décrivent les différentes étapes de la vie étudiante de la personne et ses traits de vie. Chaque faluche est unique et représente la vie de la personne au meme titre qu'un CV.

## Fonctionnalités

- Dessiner une faluche schematique en fonction de l'interaction de l'utilisateur
- Sauvegarder la faluche dans un fichier JSON
- Charger la faluche depuis le fichier JSON
- Afficher la faluche
- Sauvegarder la faluche dans un fichier image

## Les regles de la faluche

La faluche repond a un "code" (au sens règlement) national, qui peut être décliné (personalisé) en fonciton des villes. Nous nous attarderons ici sur le code d'Amiens.
La derniere version du code national est la 136eme (update annuelle) , il est lisible ici : https://faluche.app/codes/archives-national/136-toulouse-juillet-2024
